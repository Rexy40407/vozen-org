Module map

Choose the part of Helper you want to understand.

These are the runtime surfaces being shaped now. Nothing here opens a server or asks for an invite.

Core / StudioFoundation

Start with a setup that explains itself.

Helper keeps the first run legible: discover the available modules, confirm the permissions each one needs, and see the server's health without guessing.

  • Module discovery and guided setup
  • Permission passport before a feature runs
  • Status, plan, and privacy entry points
  • Scoped export and delete controls

Command surface/setup/modules/status/permissions

SecurityBounded safeguards

Protect the server without turning it into a black box.

Moderation cases, join safety, quarantine, and audit signals stay visible to the people responsible for the community.

  • Cases with reasons and moderation history
  • Join gate and configurable anti-raid latch
  • Quarantine and recovery paths
  • Native AutoMod and anti-nuke audit

Command surface/warn/quarantine/anti-raid/anti-nuke

SupportFunctional core

Make “I need help” a clear, private handoff.

Tickets can be routed, claimed, closed, and kept accountable without exposing a member's issue to the whole server.

  • Private ticket panels and routing
  • Claim, close, and durable transcripts
  • SLA reminders for the support team
  • Rate and feedback hooks after resolution

Command surface/ticket-panel/ticket-config/ticket-update

EventsFunctional lifecycle

Give plans a place to become shared moments.

Native events, polls, and giveaways cover the small rituals that make a Discord server feel alive and organised.

  • Scheduled events with registration
  • Attendee check-in and lists
  • Polls with bounded voting
  • Giveaways with scheduled close and reroll

Command surface/event-create/event-checkin/poll/giveaway-start

CommunityEveryday rituals

Keep the good parts of a community in motion.

Lightweight routines reward participation and give members useful ways to find their place.

  • XP, ranks, and server leaderboards
  • Self-role panels and suggestions
  • AFK, reminders, and reusable tags
  • Welcome, starboard, and server stats

Command surface/rank/leaderboard/rolepanel/suggest

AutomateBounded MVP

Remove repeat work, keep the rule visible.

Start with small message workflows: an optional contains condition, a reply action, and a dry-run before anything is enabled.

  • Message trigger with optional condition
  • Reply action with durable workflow runs
  • Dry-run for safer iteration
  • Toggle and delete controls for owners

Command surface/workflow-create/workflow-dry-run/workflow-toggle

InsightsTraceable by design

See what is happening, without collecting everything.

Operational stats and privacy controls give owners context while keeping the product's data boundary explicit.

  • Case, server, and workflow statistics
  • Quotas and analytics endpoints
  • Privacy receipts and scoped audit trails
  • Configuration export and delete paths

Command surface/cases/serverstats/privacy

StudioAvailable

A local control room for the people running the server.

The panel follows the same rules as the bot: clear permissions, calm status, and no hidden actions. It is ready for owners.

  • Guild-aware configuration workspace
  • Feature state and rollout visibility
  • Permission-aware actions
  • Privacy and entitlement context

Command surface/dashboard/plan/status
