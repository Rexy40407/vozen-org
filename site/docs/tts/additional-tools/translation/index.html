ADDITIONAL TOOLS

Translate text and speech input

Translation has two public paths: a private one-off translation and an optional before-speaking preference. Automatic channel mappings are server controls.

PRIVATE TEXT

Translate without posting a public result

/translate text text:Olá locale:en

This command sends the translation only to you. Use /translate language to save your usual language.

OPTIONAL SPEAKING PATH

Translate before Vozen speaks

/translate speak-language locale:en enables the preference; use locale:off to disable it. If the service is unavailable, Vozen safely reads the original text instead of inventing a translation.

Members can use /translate opt-out to opt out of configured automatic translations. Administrators can inspect or manage mappings with status, enable, disable, clear, map-add, map-remove, map-list and preview.

Translation is opt-in where it changes speech.

A one-off private translation is different from a server mapping. Document the scope clearly so a member knows whether text will be posted, spoken or returned privately.
