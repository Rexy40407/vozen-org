ADDITIONAL TOOLS

Create private audio files

/tts-file is the compact path for sharing a voice result privately. It accepts text up to 500 characters and does not join a call.

01 · WriteEnter a short fictional or personal text.
02 · RenderVozen uses the selected voice route without opening a voice session.
03 · DeliverThe result is returned as a private audio file.
04 · UseDownload or listen to the attachment in Discord.
05 · DiscardVozen current Vozen list says the generated file is not stored after delivery.

COMMAND

/tts-file

/tts-file text:This is a private audio check.

If the text exceeds the public 500-character option limit, shorten it before retrying. If the selected voice is unavailable, choose another current catalogue voice.
