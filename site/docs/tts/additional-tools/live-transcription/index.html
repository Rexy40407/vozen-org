ADDITIONAL TOOLS

Use live transcription

Live transcription is a server Premium feature. It is deliberately bounded by a visible announcement, member consent and explicit start/stop/revoke commands.

SESSION COMMANDS

Start, stop or revoke

CommandRequirement
/transcribe startManage Server, Premium server, active voice session and a target language or server default.
/transcribe stopManage Server; stops the current server session.
/transcribe revokeAny consenting member can withdraw their consent for that server.

CONSENT

What members should see

Starting a session posts an announcement in the target text channel. Only members who press the consent control are transcribed. If the session cannot post its announcement, Vozen rolls the start back.

Stopping or revoking does not delete transcript messages already posted in Discord. Delete those messages in Discord when appropriate.

No Premium

Use /premium info or ask a server administrator.

No voice session

Join a voice channel and run /join first.

No consent

The member is not added to the transcription set until they consent.
