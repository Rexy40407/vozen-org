SERVER CONFIGURATION

Review settings in the dashboard

The dashboard is useful when a server has several channel profiles. It should make the source, default voice, engine, language, speed and limits visible in one place.

BOUNDARIES

Keep examples public-safe

  • Use fictional channel names such as #lounge.
  • Do not show account tokens, guild IDs, live dashboard URLs or private screenshots.
  • Confirm the same setting with /config show when the command is available.
