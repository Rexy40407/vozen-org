SERVER CONFIGURATION

Set server defaults

Defaults are a starting point, not a lock. Members can select their own voice; administrators can keep the shared path consistent.

PUBLIC SETTINGS

The high-signal controls

CommandWhat it changes
/config default-voiceVoice used when a member has no personal voice.
/config languageServer interface language.
/config greet-languageLanguage of the join greeting.
/config auto-joinWhether Vozen joins when someone types in the configured TTS channel.
/config x-saidWhether Vozen announces who spoke.
/config showShows the current server configuration.
/config resetRestores defaults while keeping blocklist and pronunciation data.
Reset is not erasure.

Use /privacy erase for personal data removal. Use /config reset only to restore the server configuration defaults.
