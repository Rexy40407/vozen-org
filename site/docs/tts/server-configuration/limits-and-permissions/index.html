SERVER CONFIGURATION

Set limits and role gates

Limits are part of the voice experience: they keep a busy channel usable and make expensive or disruptive behaviour visible.

ControlPublic range or behaviour
/config max-chars1–2000 characters per message.
/config rate-limit1–120 messages per minute per user.
/config roleOnly members with the selected role are read.
/config priority-roleGive an accessibility queue priority role.
/config blocked-rolePrevent a role from adding audio to the queue.
/config block-wordManage the server blocklist.
/config anti-spamIgnore repeated or oversized spam patterns when enabled.

RECOVERY

Change one bound at a time

Start with the character cap or rate limit, observe the queue, then add a role gate only if the server needs it. Vozen reports invalid values instead of accepting an unbounded setting.

Members are not being read

Check the role restriction and the channel override.

Queue is too busy

Lower the rate limit or enable anti-spam.

Accessibility priority is missing

Review the priority role and its position in Discord.
