SERVER CONFIGURATION

Bind channels and sessions

The server configuration separates a text source from a voice destination. That keeps a server’s message flow understandable when several voice channels are active.

01 · Text sourceChoose a text channel with /config tts-channel.
02 · Read policyEnable auto-read and decide whether bot messages, voice-channel text or anti-spam are included.
03 · Voice contextMembers use /join in the voice channel they want.
04 · ProfileA channel profile can carry its own default voice, engine, language, speed and limits.
05 · ObserveUse /config show to inspect the current public settings.

DASHBOARD

Use the dashboard for review

The public dashboard can present server and channel profiles as a review surface. Discord commands remain the canonical public control path; never copy private dashboard URLs or identifiers into a documentation example.
