PRIVACY AND SERVICE HEALTH

Privacy and data controls

Vozen keeps the public voice path bounded: messages are processed for speech, private audio files are not stored after delivery, and live transcription requires consent.

PERSONAL ERASURE

/privacy erase

The confirmation flow deletes erasable personal data across servers, including voice settings, spoken nickname, personal pronunciations, birthday, game scores, talk statistics and opt-out state. It cannot be undone.

Paid Premium/Plus and the purchase history required for financial records are retained. Erasure is not a payment cancellation.

CONTENT BOUNDARIES

Know where a result lives

  • /tts-file returns a private attachment and the current Vozen list says it is not stored after delivery.
  • Queue views expose metadata, not a public transcript of every message.
  • Live transcription posts messages to Discord. Revoke consent stops future transcription for that member; it does not delete messages already posted.
  • Translation mappings and preferences are server/member configuration, not a public command log.
Use Discord for Discord content deletion.

If a transcript message is already in a channel, delete it there according to the server’s moderation and retention policy.
