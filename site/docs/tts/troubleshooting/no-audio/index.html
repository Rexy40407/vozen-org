TROUBLESHOOTING

No audio is heard

Separate session membership, queue state, engine availability and local Discord output before changing several settings.

CHECK IN ORDER

Four short checks

  1. Run /queue show and confirm there is an item or use /tts for a new test.
  2. Confirm Vozen has Speak in the current voice channel.
  3. Use /voice preview with a current catalogue voice.
  4. Use /shut-up, then /join, then retry a short /tts message.
Queue is paused

Use /queue resume if you have the server permission.

Paid route unavailable

Switch to Piper or let the documented fallback select the free route.

Discord output muted

Check the member’s local voice volume and the channel’s Speak permission.
