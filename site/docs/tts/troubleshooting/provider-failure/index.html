TROUBLESHOOTING

A service failed

If a voice, translation or transcription option is not working, try a different available choice first.

SPEECH

Choose another voice first

Use /voice browse or select Piper in /voice set. If a Premium voice is unavailable, choose another voice and try again.

OTHER TOOLS

Translation and transcription are separate

Translation and live transcription can be available at different times. If one is unavailable, try again later or use the other tool.

Retry later

A temporary service issue can clear without changing any settings.

Use Piper

Piper is a free voice option you can try.

Check service health

Use the public Vozen status page to see whether the service is working.
