TROUBLESHOOTING

Missing permissions

Use the permission reference and Vozen’s command response together. Do not grant broad administrator access as a first fix.

SymptomFirst check
No setup replyView Channel and Send Messages in the setup channel.
Bot cannot joinConnect in the target voice channel.
Bot joins but is silentSpeak in the target voice channel.
Config command deniedManage Server for server-wide settings.
Transcription unavailableManage Server, Premium server and member consent.
Role position still matters for Discord actions.

If a feature changes roles, channels or other server resources, review role hierarchy separately. TTS playback itself still needs the channel voice permissions.
