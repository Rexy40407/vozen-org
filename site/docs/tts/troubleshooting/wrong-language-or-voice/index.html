TROUBLESHOOTING

Wrong language or voice

A different sound can come from a personal voice, a server default, automatic detection, translation-before-speaking or an engine fallback.

DIAGNOSE

Trace the selection

  1. Run /voice recent and /voice list.
  2. Turn detection off temporarily with /voice detection active:false.
  3. Run /voice set with an explicit model and engine.
  4. Check /translate speak-language; use locale:off if it is not wanted.
  5. Preview the voice before returning to auto-read.
Model unavailable

Browse the current catalogue instead of reusing an old model name.

Detection changed voice

Turn detection off for one fixed voice.

Translation changed text

Disable translate-before-speaking or check the target locale.
