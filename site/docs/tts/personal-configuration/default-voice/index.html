PERSONAL CONFIGURATION

Set a default voice

A personal voice wins over the server default for that member. Resetting it returns the member to the server’s configured default.

01 · BrowseUse /voice list or /voice browse.
02 · PreviewUse /voice preview before saving.
03 · SetUse /voice set with a model, optional speed and engine.
04 · SpeakRun /tts or type in the auto-read channel.
05 · ResetUse /voice reset to return to the server default.

SERVER FALLBACK

What happens without a personal choice?

Administrators can set /config default-voice. Members without a personal voice use that server default. A model that is not available on the current instance is rejected or falls back through the documented engine route.
