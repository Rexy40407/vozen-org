Teach Vozen pronunciations

Pronunciation rules replace how a term is spoken. Personal rules affect only your messages; server rules apply to everyone in the server.

PERSONAL

/pronunciation

Add, remove and list your own terms with add, remove and list.

SERVER

/server-pronunciation

Administrators can add, remove and list server-wide terms for everyone.
