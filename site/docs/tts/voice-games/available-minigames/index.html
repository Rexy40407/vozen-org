VOICE GAMES

Available minigames

The catalogue below is generated from the English game names and descriptions in the committed voice-current Vozen list.

GameHow it works
Guess the LanguageI read a sentence in a random language — first to name it wins the point.
Mental MathI say a sum out loud — first to type the answer wins.
Missing NumberI count out loud but skip one number — first to catch it wins.
Spelling BeeI say a word — first to spell it correctly wins.
Unscramble the SpellingI spell a word letter by letter — first to write the whole word wins.
Fast TalkI read a sentence super fast — first to type what I said wins.
Funny AccentI say a word with a foreign accent — first to write it wins.
ReflexesI count down, then shout GO — first to type after that wins. Don't jump early!
Vozen SaysOnly obey when the order starts with 'Vozen says'. Fall for a trap and you're caught!
Truth or Dare RouletteI spin and read one truth-or-dare prompt out loud. Run it again for another.
HangmanGuess the word one letter at a time — 6 misses and it’s over.
WordleGuess the 5-letter word. 🟩 right spot, 🟨 wrong spot, ⬛ not in word. 💎 Premium.
Tic-Tac-ToeTwo players — type a number 1-9 to place your mark. Three in a row wins.
ChessTwo players — real chess rules (check, castling, promotion…). Type a move like "e4" or "Nf3". 💎 Premium.
Word ChainTurn-based word chain in one language: say a word starting with the last letter of the previous one. 2 lives, no repeats, the clock speeds up. Pick the language with the `language` option. 💎 Premium.
Heads or TailsCall the coin flip — type heads or tails before I flip. Best guesser wins!
Premium games are marked by Vozen.

The current public copy marks Wordle, Chess and Word Chain as Premium. Use /game list in Discord for the current availability on the server.
