VOICE GAMES

Start and stop a game

A game needs a voice session and a free game slot on the server.

01 · Join voiceRun /join before starting a voice game.
02 · Pick a gameUse /game play or inspect the list first.
03 · Play the roundVozen reads prompts and members answer in the text channel.
04 · Stop earlyUse /game stop when the current round should end.
05 · ReviewUse /game leaderboard or /game stats.

GUARDRAILS

One active game per server path

Vozen reports when another game is already active, when there are not enough players, or when the selected game has no current voice-language data. A stop action ends the game; it does not erase historical scores.

Not in voice

Join a voice channel and run /join.

Game already active

Finish it or run /game stop.

Premium game locked

Check /premium info.
