VOICE GAMES

Game permissions and limits

Game participation needs the same voice path as TTS, plus a text channel where members can answer and see the round.

BoundaryWhy it matters
Connect and SpeakVozen must read the prompt in the voice channel.
View and Send MessagesMembers need to see prompts and submit answers.
Current voice languageSome language games need a word list or voice data.
One active gameA server has one current game path at a time.
Premium entitlementWordle, Chess and Word Chain are Premium in the current current Vozen list.

SCORES

Scores are not configuration

/game leaderboard and /game stats read game score data. For personal data erasure, use /privacy erase; stopping a game only stops its current activity.
