Vozen TTS docs/Public command reference

REFERENCE

Public command reference

This page lists the commands people can use in Discord.

What is listed

If a command is not on this page, do not use it.

/invite

Show the link to add Vozen to your server

/vote

Show the link to vote for Vozen on top.gg

/help

Show Vozen's command list

/join

Join your voice channel

/leave

Leave the voice channel

/tts

Vozen reads a text out loud

text · required
What to read
/tts-file

Create a private audio file from short text (does not join a call)

text · required
Short text to turn into audio Max 500 characters.
/skip

Skip the current audio

/queue

View or manage the privacy-safe playback queue

/queue show

Show pending queue metadata

/queue remove

Remove one of your queued items (admins may remove any item)

id · required
Opaque queue item id
/queue clear

Manage Server: clear queued audio

/queue skip

Manage Server: skip current audio

/queue pause

Manage Server: pause audio

/queue resume

Manage Server: resume audio

/shut-up

Make Vozen stop talking now (clears the whole queue)

/laugh

Vozen laughs out loud in your current voice

/joke

Vozen tells a short joke in the language you pick

language · required
Language of the joke
laughter · required
Add laughter at the end?
engine
Voice engine (optional) Choices: Default (Google TTS), Piper, 💎 Kokoro (Premium neural).
/rizz

Vozen drops a pickup line in the language you pick (💎 Premium)

language · required
Language of the pickup line
engine · required
Voice engine (required) Choices: Default (Google TTS), Piper, 💎 Kokoro (Premium neural).
sound
Add the rizz sound effect at the end? (optional)
/sound

Play a sound clip in the voice channel

name
Which sound to play (leave empty to list them) Choices: 📢 Air horn, 🔔 Ding, ❌ Wrong buzzer, 🎉 Ta-da!, 🎺 Sad trombone, 🔊 Beep, 🪙 Coin, 🫧 Pop, 🛸 Laser, ✅ Success, ⛔ Error, 🪀 Boing, ✨ Sparkle, 💨 Whoosh.
/8-ball

Ask the magic 8-ball a yes/no question

question · required
Your yes/no question Max 200 characters.
language · required
Language of the answer
engine · required
Voice engine (required) Choices: Default (Google TTS), Piper, 💎 Kokoro (Premium neural).
/fortune

Vozen reads you a fortune

language · required
Language of the fortune
engine · required
Voice engine (required) Choices: Default (Google TTS), Piper, 💎 Kokoro (Premium neural).
/cast

Randomly cast everyone in your voice call

/fact

Vozen tells you a random fun fact

language · required
Language of the fact
engine · required
Voice engine (required) Choices: Default (Google TTS), Piper, 💎 Kokoro (Premium neural).
/wyr

Vozen asks a "would you rather" question

language · required
Language of the question
engine · required
Voice engine (required) Choices: Default (Google TTS), Piper, 💎 Kokoro (Premium neural).
/birthday

Vozen wishes you a happy birthday when you join on your day

/birthday set

Set your birthday (day + month, no year)

day · required
Day of the month (1–31)
month · required
Month (1–12)
/birthday clear

Remove your saved birthday

/birthday show

Show your saved birthday

/privacy

Manage your personal data

/privacy erase

Permanently delete all your personal data (asks you to confirm first)

/translate

Configure opt-in text translation (never speaks translated text)

/translate text

Translate text privately

text · required
Text to translate Max 1000 characters.
locale
Target locale, for example en or pt
/translate language

Save your default translation language

locale · required
Target locale, for example en or pt
/translate speak-language

Translate your messages before Vozen reads them (opt-in)

locale · required
Target locale, or off to disable
/translate status

Show translation status (Manage Server)

/translate enable

Enable configured mappings (Manage Server)

/translate disable

Disable automatic translation (Manage Server)

/translate clear

Delete mappings and member translation opt-outs (Manage Server)

/translate map-add

Map a source text channel to a destination (Manage Server)

source · required
Source text channel
destination · required
Destination text channel
locale · required
Target locale, for example en or pt
/translate map-remove

Remove a source channel mapping (Manage Server)

source · required
Source text channel
/translate map-list

List channel mappings (Manage Server)

/translate preview

Preview a translation without posting it (Manage Server)

text · required
Text to translate Max 1000 characters.
locale · required
Target locale, for example en or pt
/translate opt-out

Opt in or out of automatic translation for your messages

active · required
Turn opt-out on or off
/top-speakers

See who Vozen has read the most — and daily streaks

/server-stats

Server stats: messages, top talkers and games (💎 Premium, free preview)

/premium

Vozen Premium: your status, or use/free a licence on this server

/premium info

See your Premium status — or what you get and how to buy

/premium activate

Use one of your Premium licences on this server (needs Manage Server)

/premium deactivate

Free this server’s Premium licence to use it elsewhere

/transcribe

Live speech-to-text: transcribe consenting speakers to this channel (Premium)

/transcribe start

Start transcribing the voice call to this channel (Manage Server, Premium)

language
Language spoken in the call (defaults to the server language)
/transcribe stop

Stop transcribing the voice call (Manage Server)

/transcribe revoke

Withdraw your consent to be transcribed on this server

/voice

Manage your voice

/voice set

Set your voice

model · required
Piper model
speed
Speed (0.5-2.0)
engine
Voice engine: Google TTS, Piper or Kokoro (Premium) Choices: Default (Google TTS), Piper, 💎 Kokoro (Premium neural).
/voice config

Open a panel to set up your voice (no accidental Enter)

/voice list

List the available models

/voice favorite

Add a voice to your personal favourites

model · required
Voice model
/voice unfavorite

Remove a voice from your personal favourites

model · required
Voice model
/voice favorites

Show your favourite voices

/voice recent

Show your ten recent voices

/voice browse

Browse the currently available voice catalog

query
Search by voice or language Max 50 characters.
locale
Two-letter voice language, for example en Max 2 characters.
engine
Catalog engine Choices: All available voices, Local catalog voices, Google catalog voices.
/voice reset

Reset your voice to the default

/voice detection

Native voice per language (the speaker may change). Off by default.

active · required
On = native voice per language; Off (default) = one fixed voice
/voice opt-out

Stop being read automatically in the auto-read channel

/voice opt-in

Be read automatically again in the auto-read channel

/voice preview

Preview a language/model with a selected voice engine

model
Language and voice model (optional)
engine
Voice engine (optional) Choices: Default (Google TTS), Piper, 💎 Kokoro (Premium neural).
/voice nickname

How Vozen should call you out loud (xsaid). Leave empty to clear.

name
Spoken name (empty = use your server name) Max 40 characters.
/voice effect

Apply a voice effect to your messages (💎 = Premium)

effect · required
Voice effect (none = clean; 💎 needs Premium) Choices: None (normal), 🤖 Robot, 🔊 Echo, 💎 🕳️ Deep, 💎 🐿️ Chipmunk, 💎 📻 Radio, 💎 📞 Phone, 💎 🌊 Underwater, 💎 😈 Demon.
