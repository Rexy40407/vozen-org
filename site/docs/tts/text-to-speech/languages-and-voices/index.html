TEXT TO SPEECH

Choose languages and voices

Browse the voices by language. Use /voice browse in Discord when you need the latest choices.

BROWSE

Three useful voice commands

  • /voice list shows the locally available models.
  • /voice browse searches the catalogue by query, locale or engine.
  • /voice preview plays a short sample before you switch.

Use /voice set model:… speed:1.0 to save a voice. The supported speed range is 0.5 to 2.0.
