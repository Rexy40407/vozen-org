TEXT TO SPEECH

Use automatic language detection

Automatic detection is opt-in and off by default. With it enabled, the speaker may change from message to message so the detected language has a matching voice.

TOGGLE

One command, one visible preference

/voice detection active:true\n/voice detection active:false

When detection is off, the member’s fixed voice reads everything. When it is on, Vozen resolves a voice for the detected locale and falls back safely when it cannot.

Detection is not a translation service.

It selects a voice for the detected language. Use the translation commands when the text itself must be translated.

Too many language switches

Turn detection off and select one fixed voice.

Unsupported locale

Use /voice browse to inspect the current catalogue.

service unavailable

Retry with a local voice or follow service troubleshooting.
