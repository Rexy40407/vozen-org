TEXT TO SPEECH

Understand the queue

Vozen queues audio, not a public transcript. Queue views expose only the metadata needed to manage playback.

QUEUE CONTROLS

Member and administrator actions

CommandWho can use itEffect
/queue showMembersShow pending queue metadata.
/queue removeMember or administratorRemove one queued item; administrators may remove any item.
/queue clearManage ServerClear queued audio.
/queue skipManage ServerSkip the current item.
/queue pauseManage ServerPause playback.
/queue resumeManage ServerResume playback.
/skipMembersSkip the current audio item.
/shut-upMembersClear the whole queue immediately.

RECOVERY

Keep playback predictable

Use /queue show to inspect the state, then remove or skip the smallest item that is blocking progress. Use /shut-up when the correct action is immediate silence, not a re-ordered queue.
