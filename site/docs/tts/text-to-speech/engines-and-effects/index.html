TEXT TO SPEECH

Voice engines and effects

Engine selection and effect selection are separate. An engine chooses how speech is synthesized; an effect changes the resulting sound.

SETTINGS

Use the public commands

/voice set accepts a model, optional speed and optional engine. /voice effect accepts none, Robot, Echo, Deep, Chipmunk, Radio, Phone, Underwater or Demon. Robot and Echo are the free effects; the remaining effects are Premium-gated.
