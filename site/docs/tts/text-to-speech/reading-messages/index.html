TEXT TO SPEECH

Read messages

Auto-read is a server choice. Personal voice settings change how a member sounds, not which channels the server allows.

AUTO-READ

Choose a text source

Use /setup for the guided path or /config tts-channel to change the channel later. Auto-read is off until the server enables it.

/config tts-channel channel:#lounge\n/config auto-read active:true

SPEAKER CONTEXT

Make the voice traceable

/config x-said active:true adds a spoken “name said” lead-in. A member can set a spoken nickname with /voice nickname. Bots and webhooks are ignored by default; administrators can opt in with /config read-bots active:true.

Wrong channel

Check the configured TTS channel and its View Channel permission.

Unexpected bot messages

Review the read-bots toggle and channel sources.

Too much output

Use a character cap, rate limit, blocked role or anti-spam.
