GETTING STARTED

Install Vozen TTS

The public install flow is designed to end in a working, explainable setup instead of a long settings tour.

01 · Add the appUse the public Vozen invite and select a server where you can manage the server.
02 · Review accessKeep the permissions Discord shows in the install screen, then review channel overrides.
03 · Run setupUse /setup; optionally choose a text channel and a short voice check.
04 · Join voiceEnter a voice channel and run /join.
05 · Test onceSend a small message or run /tts before inviting everyone into the flow.

FIRST COMMAND

/setup is the starting point

/setup accepts an optional text channel and an optional test voice. If the channel is omitted, the current text channel is used. Vozen checks the text-channel and voice-channel permissions it can verify, then reports any missing item.

/setup channel:#lounge test-voice:true
Never paste secrets into setup.

Vozen’s public installation needs Discord’s app flow, not a bot token, guild ID or private configuration file.

RECOVERY

If the setup report is incomplete

Fix the marked permission on Vozen’s role or on the channel override, then run /setup again. The setup message is safe to repeat. It does not require a private dashboard route.
