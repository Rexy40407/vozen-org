GETTING STARTED

Permissions that matter

Discord permissions are evaluated at the server and channel level. A role can have the right capability globally while a channel override still blocks it.

CapabilityUsed forWhere to check
View ChannelSee the configured text channel and voice-channel context.Text and voice channel overrides
Send MessagesReply with setup, queue, privacy and command results.Text channel
ConnectJoin a voice channel.Voice channel
SpeakPlay TTS audio in a voice channel.Voice channel
Manage ServerRun server configuration, Premium activation and live transcription controls.Member role and command context
Message Content intentRead messages in the configured auto-read channel.Application configuration and server setup

CHECKLIST

Use the smallest useful check

  1. Check the text channel where /setup is run.
  2. Check the configured auto-read channel.
  3. Check the voice channel for Connect and Speak.
  4. Run /join while in the target voice channel.
