GETTING STARTED

Start your first voice session

Keep the first test small. A single command confirms the voice path without requiring auto-read.

01 · Join a voice channelYou join the call first; Vozen does not guess which voice channel you mean.
02 · Connect VozenRun /join. Vozen checks Connect and Speak in that channel.
03 · Read one messageRun /tts Hello from the voice test.
04 · Watch the queueIf another item is playing, the new audio waits behind the current item.
05 · Leave when doneRun /leave or use /shut-up when you need the queue cleared now.

PREVIEW

Use a message that cannot be mistaken for production content

Try /tts This is a private setup check.. The response and audio confirm the active voice, engine route and session without exposing a real member or server.

No voice channel

Join a voice channel before running /join.

Connect or Speak denied

Check the role and channel override, then retry.

Nothing heard

Use the no-audio troubleshooting page and inspect the queue.
