GETTING STARTED

Meet Vozen TTS

Vozen turns readable Discord messages into ordered voice output. Members can choose their own voice; administrators control the server channel, defaults and limits.

WHAT IT DOES

One voice path, several controls

The core flow is intentionally small: join a voice channel, connect Vozen, choose where text comes from, and let the queue handle playback. Personal voice preferences do not replace the server’s safety controls.

  • Auto-read can be tied to one text channel.
  • /tts reads a single text immediately.
  • Personal voices, speeds, engines and effects can be changed without changing another member’s voice.
  • Private tools such as /tts-file and /translate text do not require Vozen to join a call.
The free path is complete.

Piper voices, the core auto-read flow and the administrative controls are part of the free core. Premium adds optional engines and higher-cost extras.
