    功能

    你的伺服器所需的一切

    一個機器人，涵蓋你一直希望 Discord 擁有的所有語音功能——而且核心功能永久免費。

    自動朗讀頻道

    選定一個頻道，Vozen 就會大聲朗讀每一則訊息。用 /setup 一次設定完成。

    你的語音，你的語言

    每位成員都能從 35 種語言中挑選自己的語音——Google 或本地神經網路引擎皆可。

    說起話來像真人

    預設使用你選擇的語音。可用 /voice detection on 啟用每則訊息的選用語言偵測；! 和全大寫會加強語氣。

    16 款語音小遊戲

    猜語言、拼字比賽、Wordle、反應對決——還有伺服器排行榜。

    自帶個性

    向加入的成員打招呼——而且不會重複同樣的話——送上生日祝福、講笑話、回答神奇八號球，還會追蹤伺服器中最愛講話的成員。

    讓管理員安心

    封鎖清單、速率限制、會將洗版訊息靜音的反垃圾訊息過濾器、身分組權限控管、退出選項與緊急停用開關。一切盡在你的掌控中。

    NEW

    語音特效

    機器人、回音、低沉、花栗鼠、廣播、惡魔……你的訊息，隨心變換。免費提供兩種特效，升級 Premium 即可享用全部八種。

    公道的 Premium

    每月 €6.99 可解锁 Kokoro 和服务器附加功能；基础 Piper 核心仍然免费。

    NEW

    隨處可用的私人工具

    使用 /tts-file 和 /translate text，或右鍵點擊訊息，私下翻譯或轉錄支援的 Discord 音訊，不必加入通話

    頻道設定檔

    從安全的伺服器控制面板為每個頻道設定自己的語音、引擎、語言、速度、限制與語音頻道繫結

    最愛語音

    儲存最多 25 個最愛語音，無需再次搜尋完整資料庫即可回到最近使用的 10 個語音

    開放原始碼

    Vozen 的所有程式碼都公開在 GitHub 上。你可以稽核、學習，或發起 PR——沒有秘密，沒有間諜軟體。
