    기능

    서버에 필요한 모든 것

    하나의 봇으로. Discord에 있었으면 했던 모든 음성 기능 — 핵심 기능은 영원히 무료입니다

    자동 읽기 채널

    채널을 선택하면 Vozen이 모든 메시지를 소리 내어 읽어드립니다. /setup으로 한 번만 설정하세요

    나만의 음성, 나만의 언어

    모든 멤버가 35개 언어 중에서 자신만의 음성을 선택합니다 — Google 또는 로컬 뉴럴 엔진으로

    사람처럼 말합니다

    기본적으로 선택한 음성을 사용합니다. 메시지별 선택적 언어 감지는 /voice detection on으로 켤 수 있으며 !와 대문자는 강조를 더합니다

    16가지 음성 미니게임

    언어 맞히기, 스펠링 비, Wordle, 반응 속도 대결 — 서버 리더보드와 함께

    개성까지 담았습니다

    새로 들어온 사람을 반겨주고 — 매번 다르게 — 생일을 축하하고, 농담을 하고, 매직 8볼에 답하며, 서버에서 가장 많이 말한 사람을 기록합니다

    관리자도 안심

    차단 목록, 속도 제한, 도배 메시지를 음소거하는 스팸 방지 필터, 역할 제한, 참여 거부, 그리고 킬 스위치까지. 통제권은 언제나 당신에게 있습니다

    NEW

    음성 효과

    로봇, 에코, 저음, 다람쥐, 라디오, 악마… 당신의 메시지가 변신합니다. 두 가지 효과는 무료, 여덟 가지 전부는 Premium으로

    공정한 Premium

    월 €6.99로 Kokoro와 서버용 부가 기능을 잠금 해제합니다. 필수 Piper 핵심 기능은 계속 무료입니다

    NEW

    어디서나 사용하는 비공개 도구

    /tts-file 및 /translate text를 사용하거나 메시지를 마우스 오른쪽 버튼으로 눌러 통화에 참여하지 않고 지원되는 Discord 오디오를 비공개로 번역하거나 전사하세요

    채널 프로필

    안전한 서버 대시보드에서 각 채널의 음성, 엔진, 언어, 속도, 제한 및 음성 채널 연결을 설정하세요

    즐겨찾는 음성

    최대 25개의 음성을 저장하고 전체 라이브러리를 다시 검색하지 않고 최근 사용한 10개로 돌아가세요

    오픈 소스

    Vozen의 모든 코드는 GitHub에 공개되어 있습니다. 직접 검토하고, 배우고, PR을 열어보세요 — 비밀도, 스파이웨어도 없습니다

    미니게임

    소리 내어 즐기세요

    음성을 위해 만든 16가지 미니게임: 자신의 언어로 즐기는 턴제 끝말잇기(Vozen이 각 단어를 소리 내어 읽어줍니다), 들려주는 언어 맞히기, 초고속 발화 해독, 스펠링 비, 반응 속도 대결, 여기에 Wordle, 행맨, 틱택토, 그리고 실제 그래픽 보드로 즐기는 체스까지. 모든 서버가 리더보드를 유지합니다

    • 서버 리더보드 및 개인 통계
    • Vozen이 승자를 소리 내어 발표합니다
