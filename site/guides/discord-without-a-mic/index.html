TTS GUIDE

No mic? Stay in the Discord conversation.

Vozen reads your messages into the voice channel, so you can reply by typing when speaking is inconvenient or simply not possible.

A calm first setup

01

Add it to one server

Choose a server where you can manage the server. Discord shows the requested permissions before anything is installed.

02

Run /setup

Set a text channel you want read aloud. Keep the bot role below any role it needs to manage.

03

Make one small test

Join voice with /join, type a short message, and adjust the voice only after the first playback works.

Use it without taking over the room

Tell the people in the channel that a typed reply will be played aloud. Keep the first messages short and choose a voice that is easy to understand. Members can later choose their own language and voice; the server admin can keep automatic reading limited to the intended text channel.

  • Use a dedicated channel for frequent messages, so private or off-topic chat is not read accidentally.
  • Keep channel overrides explicit: Vozen needs to view the chosen text channel and connect/speak in the voice channel.
  • Use the dashboard or /config to tune behaviour only after the basic test succeeds.
Privacy reminder. Do not send passwords, access tokens or private account details to any Discord bot or setup flow. If audio does not play, review the channel permissions and retry /setup.
