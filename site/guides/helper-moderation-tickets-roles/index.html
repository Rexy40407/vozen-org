HELPER GUIDE

Start your server operations with one useful module at a time.

Vozen Helper groups moderation, tickets, role panels, events and automations in one product. Begin with the module that solves today’s problem, then grant only the permission it explains.

A safe first-module order

01 · MODERATION

Protect the public conversation

Begin with a narrowly-scoped moderation rule and the channels it should cover. Keep the Helper role below roles it must not manage.

02 · TICKETS

Give support a private queue

03 · ROLES

Let members choose safe roles

Create one role panel with roles below the Helper role. Test both assignment and removal, then add optional panels.

Role panels documentation

Permission passport before each module

Do not grant a broad permission in the hope it fixes an unclear error. Review the module’s stated purpose, Discord’s prompt and the target channel/category. If Vozen Helper reports a missing permission, grant it only where that module needs to act, then rerun the action.

  • Never paste a bot token, account token or password into a Discord command, panel or support message.
  • Keep audit, moderation and support boundaries visible to the staff who own them.
  • Use the missing-permissions guide when a setup step stops.
An installation is only the start. The useful product event is the first configured module completing its first action; that is the activation point tracked in the private panel.
