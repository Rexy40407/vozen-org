VOICE GAMES

Voice games are their own path

Games use the same voice session as TTS but have their own start, stop, score and Premium rules. They are documented separately so a server can choose whether to enable the playful path.

COMMANDS

Game controls

  • /game list shows the available games.
  • /game play starts a game selection flow.
  • /game stop stops the active game.
  • /game leaderboard shows the server leaderboard.
  • /game stats shows your own game stats.
Games are optional.

They do not change the auto-read channel, personal voice or server defaults.
