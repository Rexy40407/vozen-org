Permission reference

A permission may be valid at the role level and still blocked by a channel overwrite. Check the exact channel where a command or session runs.

PermissionPublic path
View ChannelRead the configured text channel and show replies.
Send MessagesReturn command results and private-tool responses.
ConnectJoin the selected voice channel.

Manage ServerChange server config, activate Premium and control live transcription.
