REFERENCE

Spoken variables and output

Vozen does not publish a general-purpose message template language for TTS. Vozen owns the final spoken text and protects Discord mentions while preparing it.

SPEAKER ANNOUNCEMENT

{name} is an output marker

When /config x-said is enabled, the public current Vozen list describes the spoken shape as “{name} said …”. The name comes from the member’s display context or their /voice nickname; it is not a free-form server template.

PRONUNCIATION

Replace speech, not messages

Personal and server pronunciation rules transform the spoken form of a matching term. The original Discord message stays as written, and the rule scope remains personal or server-wide.

No private placeholders.

Do not publish tokens, IDs, internal interpolation keys or owner-only output names as if they were public variables.
