PREMIUM AND PLUS

Understand Plus and Premium

The public entitlement model has two scopes: personal extras follow a Discord account; server Premium makes selected extras available to everyone in an activated server.

ScopeWhat it unlocksActivation
Free corePiper voices, 35 locales, auto-read, core controls and most games.No paid activation.
Vozen PlusPersonal Premium engines, all voice effects, personal pronunciation uplift and personal extras on any server.Account entitlement; check /premium info.
Vozen PremiumServer-wide engines/effects, higher server pronunciation capacity, 24/7 in-call, Premium games and live transcription.Use /premium activate with Manage Server.

PUBLIC COMMANDS

Inspect and move an activation

/premium info shows the current status. /premium activate uses one available Premium licence on the server. /premium deactivate frees that server licence to use elsewhere; the pass clock continues.

Premium does not change privacy boundaries.

Paid access changes feature availability and limits. It does not turn private queue metadata, message text or consent into public data.
