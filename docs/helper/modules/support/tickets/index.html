What this does

Turn member requests into private, trackable support conversations.

When to use it

Use this module when you want a clear, server-scoped way to support tickets. Start with the recommended setup, then open advanced options only when you know what you need.

CONFIGURE

Recommended setup

  3. Choose the recommended defaults, simulate the change, and publish only after the preview is correct.

SIMULATION AND RECOVERY

Preview, health and rollback

Use the panel simulation to see the matched rules and expected effects before publishing. The panel also reports health and dependency problems. Published revisions can be reverted without deleting history.

Open in Helper panel

TROUBLESHOOTING

Common problems

  • If the panel reports a missing permission, check both the bot role and channel-specific overwrites.
  • If a resource was deleted, refresh the server context before publishing again.
  • If a provider is unavailable, pause the subscription and follow the provider status page.

Data and related features

Vozen stores only the configuration and event data required by the module. Content retention, if offered, is opt-in and bounded by the server policy.
