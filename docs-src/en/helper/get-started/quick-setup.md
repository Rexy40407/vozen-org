# Quick Setup

Use this short path to make the first useful changes without guessing at permissions. You can return to any step later.

1. **Protect the server** - start with anti-spam and entry protection.
2. **Welcome members** - choose a real channel and a short message.
3. **Create a signal** - enable levels or a simple role panel.
4. **Review** - resolve preflight warnings and run the preview.
5. **Publish** - save one revision, then watch health for the first few minutes.

## Before you publish

The panel checks the selected server, effective channel permissions, role hierarchy, and provider dependencies. A blocked module is informational only; it cannot be activated from Quick Setup.

## Continue in the panel

[Open the Helper panel](https://vozen.org/panel/helper-tracker/#/quick-setup) or read [missing permissions](/docs/helper/troubleshooting/missing-permissions/) if a step cannot be published.
