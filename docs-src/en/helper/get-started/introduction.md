# Welcome to Vozen Helper

Vozen Helper is a Discord bot and web panel for server owners. This documentation starts with tasks, then opens the technical detail when you need it.

## How to use these docs

1. Pick a task that matches your goal.
2. Read the requirements before changing anything.
3. Use the panel preview and preflight.
4. Publish, observe health, and keep the revision available for rollback.

The documentation is generated from the Helper's public technical manifest. If a detail is not in that manifest, it is not presented as a guaranteed capability.
