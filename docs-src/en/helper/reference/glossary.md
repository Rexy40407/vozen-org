# Glossary

**Adapter** - the technical contract that validates, previews, publishes, and reports health for one module.

**Preflight** - a permission and dependency check immediately before a change is published.

**Revision** - an immutable published configuration snapshot that can be restored.

**Unavailable** - a dependency or approval prevents activation today; the page is informational only.
